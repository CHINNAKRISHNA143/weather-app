# 🌦 Weather App

A simple and responsive weather app built with **React** and the **Open-Meteo API**.  
It allows users to search for cities and view current weather details, including temperature, windspeed, humidity, and conditions.

---

## 🚀 Features
- Search for any city
- Fetches live weather using [Open-Meteo API](https://open-meteo.com)
- Displays:
  - 🌡 Temperature (°C & °F)
  - 💨 Windspeed & direction
  - 💧 Humidity
  - ☁️ Weather condition
- Recent searches with localStorage
- Loading spinner while fetching
- Error handling for invalid cities / network issues
- Responsive design (works on desktop & mobile)

---

## 🛠️ Tech Stack
- React
- CSS (custom styling)
- Open-Meteo Geocoding & Weather APIs
